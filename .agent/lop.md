# Lop

Each package/site is a write bubble defined by its SPEC. Read its external bar and all consumed contracts. Work in an isolated branch/worktree. Allowed writes: owned implementation/tests and the domain SPEC. Forbidden: another bubble, root package.json, workspace/lock/config, every package.json and contract.ts, next.config.ts, test/architecture, .agent, AGENTS.md and specs/00_engine.md. PM integrates milestones and resolves contract issues.

Implement → verify domain commands → architecture gate → four-part report. If a contract is wrong, report it instead of forking types. Never grade your own product. The site is the real static export; inspect it through a server, at desktop and phone widths, and exercise URL/filter behavior.
