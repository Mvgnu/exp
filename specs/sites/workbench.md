Use the frozen WorkspaceSnapshot read model. Site data is generated by `pnpm demo` from actual deterministic engine runs; never type dashboard metrics into JSX. Demo datasets clearly say synthetic. Live configuration credentials never enter the export; browser API connection uses a user-entered operator token held in session state. URL query/filter state survives reload; responsive phone and desktop; visible focus, keyboard navigation, labelled controls, good contrast, empty/error/loading/offline states. ## Implemented navigation and read model

The static entry point is `/`. All views remain available without an API connection:

| Query `view`         | Operator task                                                                                                                             |
| -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- |
| `overview` (default) | Compare projects, review highest-severity open findings, inspect source-family coverage and recent engine events.                         |
| `sources`            | Filter sources by family/status, inspect immutable versions, select observations and verify exact quoted characters in stored passages.   |
| `audit`              | Filter findings by type/status, inspect evidence and recommended action, open related schema proposals.                                   |
| `schemas`            | Review proposal status, complete field-definition diffs, nested JSON structure, historical approved schemas and affected source versions. |
| `runs`               | Inspect execution events, durable job status, recorded usage and the distinction between estimates and reported costs.                    |
| `explore`            | Inspect pinned published records, preserved disagreements and field-level evidence, or explicitly select a historical release.            |

Shared URL keys are `project`, `q`, `status`, `kind`, `detail`, `version` and `observation`. `version` refers to a source version in the source inspector and to a publication in the explorer. Query changes replace the current history entry; navigation and detail opening create history entries. Reload and browser back/forward restore state. Search has a Ctrl/Cmd+K shortcut. Source families, entity types, project labels, schema fields and all numerical summaries come from the validated snapshot.

`lib/demo.ts` validates PM-generated `data/snapshot.json` with `WorkspaceSnapshotSchema`. Browser code imports the browser-safe `@deeplake/core/contract` surface only. No source acquisition, store, provider or Node runtime code is bundled into the site. A synthetic source is labelled as a fixture and its stored text is inspected locally; `.example` fixture URLs are not presented as live third-party records.

## Operator actions

The connection form accepts an explicit API URL and operator token. The successful connection is kept in `sessionStorage`, never a `NEXT_PUBLIC_` variable or the generated export. A connection is checked by fetching and validating the actual workspace snapshot; the UI does not simulate successful mutations. Provider configuration displays only server-reported configured/not-configured state. Connection loss keeps the last snapshot visible, shows an error and disables mutations until a successful refresh.

Live actions include project creation with questions and per-run budgets; discovery and maintenance runs; reparsing a preserved original; finding resolution/dismissal with a reason; proposal approval/rejection with a reason and explicit breaking-change acknowledgement; durable job cancellation; and explicit publication of a new release. Successful actions refresh the API snapshot. No paid discovery is started merely by creating a project or connecting the workbench. Source-original downloads use the authenticated endpoint. JSON exports use the selected pinned or historical publication, never unpublished observations.

Read-only demo actions explain the API prerequisite. Source inspection, filters, schema comparison, publication exploration and JSON export remain functional. New-project and publication dialogs can be reviewed in demo mode without creating invented state. Native dialogs provide focus containment and Escape dismissal. Phone navigation uses a collapsible sidebar and detail panels use the viewport width; wide data tables scroll within their container.
